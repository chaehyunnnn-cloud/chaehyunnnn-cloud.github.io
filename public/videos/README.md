# public/videos

상세페이지 body의 video 블록이 쓰는 폴더입니다. 여기 넣은 파일은 가공 없이
그대로 배포됩니다(썸네일 파이프라인을 타지 않음).

## GIF 대신 쓰는 '움직이는 컷'

src/data/portfolio.ts 의 body 에 아래처럼 적으면 GIF와 똑같이 보입니다
— 재생바·버튼 없이, 소리 없이, 무한 반복.

    { type: 'video', src: '/videos/detail-1.mp4', motion: true }

motion 을 빼면 재생 컨트롤이 있는 일반 영상으로 나옵니다.

## 파일 만들 때

- 포맷: mp4 (H.264 + yuv420p) — 모든 브라우저·iOS에서 재생됩니다
- 소리: 필요 없습니다. muted 로 재생되므로 오디오 트랙은 빼는 게 용량에 이득
- 가로폭: 상세페이지 본문 폭에 맞춰 1600px 이하면 충분
- 루프: 첫 프레임과 끝 프레임을 비슷하게 맞추면 이음매가 티나지 않습니다
